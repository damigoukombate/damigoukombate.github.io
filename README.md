# Portfolio de Damigou KOMBATE

Site statique multipage conçu pour GitHub Pages.

## Publication

1. Ouvrir le dépôt `damigoukombate.github.io`.
2. Ajouter tous les fichiers et le dossier `assets` à la racine du dépôt.
3. Aller dans **Settings > Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**, puis `main` et `/ (root)`.
5. Enregistrer. Le site sera disponible sur `https://damigoukombate.github.io/`.
